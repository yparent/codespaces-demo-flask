# Codespaces Demo · Flask

Application Flask minimaliste pour démonstration GitHub Codespaces.

## Démarrage

1. Cliquez sur **Code** → **Codespaces** → **Create codespace on main**
2. Dans le terminal : `pip install -r requirements.txt`
3. Lancez l'app : `python app.py`
4. Cliquez sur "Open in Browser" dans la notification port forwarding

## Stack

- Python 3.12
- Flask 3.0
